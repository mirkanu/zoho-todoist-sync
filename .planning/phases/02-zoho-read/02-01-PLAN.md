<!-- Verbatim from 02-RESEARCH.md — executor uses these exact shapes. -->

**GET /crm/v8/Tasks/{id}** — Single record
  Headers: `Authorization: Zoho-oauthtoken {access_token}`
  Response 200: `{"data": [{...record fields...}]}`  (always a list with 1 item)
  Response 401: ZohoAuthError
  Response 404: ZohoNotFoundError
  Response 429: ZohoRateLimitError

**GET /crm/v8/settings/fields?module=Tasks** — Field metadata
  Response 200: `{"fields": [{"api_name": "Todoist_Task_ID", "field_label": "Todoist Task ID",
                              "custom_field": true, "data_type": "text", ...},
                             {"api_name": "Status", "data_type": "picklist",
                              "pick_list_values": [{"actual_value": "Completed", "display_value": "Completed"}, ...]},
                             ...]}`
  To find the Todoist field: iterate fields where `field.get("custom_field")` is True AND `"Todoist" in field.get("field_label", "")`.
  To find status values: find field where `api_name == "Status"` AND `data_type == "picklist"`, then extract `actual_value` from each entry in `pick_list_values`.

**GET /crm/v8/Tasks/search?criteria=...&page=N&per_page=200** — Search
  Criteria format (exact, no spaces):
    `((Modified_Time:greater_equal:2026-04-23T10:00:00+00:00)and(Owner:equals:554023000000235011))`
  Response 200: `{"data": [...records...], "info": {"per_page": 200, "count": N, "page": P, "more_records": true|false}}`
  Response 204: No Content = valid empty result (NOT an error — return []).
  Pagination: loop while `body["info"]["more_records"]` is True, increment `page`.

**Timestamp format:** `since.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S+00:00")` — always explicit UTC offset.
</key_zoho_api_contracts>

    ```python
    # app/zoho/client.py
    import httpx
    from dataclasses import dataclass
    from datetime import datetime, timezone
    from typing import Any

    from app.core.logging import get_logger

    log = get_logger(__name__)

    ZOHO_EU_BASE_URL = "https://www.zohoapis.eu/crm/v8"


    class ZohoAuthError(Exception):
        """Raised on 401 — refresh token invalid or scope mismatch. Do NOT retry — stop and alert."""


    class ZohoNotFoundError(Exception):
        """Raised on 404 — task or resource does not exist."""


    class ZohoRateLimitError(Exception):
        """Raised on 429 — Zoho concurrency limit exceeded. Retry with backoff."""


    class ZohoAPIError(Exception):
        """Raised on other non-2xx responses (5xx, unexpected 4xx)."""


    @dataclass
    class ZohoClient:
        """
        Async Zoho CRM v8 client against the EU region.
        access_token is mutable — refreshed in-place by token_manager.proactive_refresh_loop.
        """
        access_token: str
        base_url: str = ZOHO_EU_BASE_URL

        def _headers(self) -> dict[str, str]:
            return {"Authorization": f"Zoho-oauthtoken {self.access_token}"}

        def _handle(self, resp: httpx.Response, context: str = "") -> Any:
            """Map Zoho non-2xx responses to typed exceptions. Returns parsed JSON on 2xx."""
            if resp.status_code == 401:
                raise ZohoAuthError(f"401 Unauthorized — {context}")
            if resp.status_code == 404:
                raise ZohoNotFoundError(f"404 Not Found — {context}")
            if resp.status_code == 429:
                raise ZohoRateLimitError(f"429 Rate limit — {context}")
            if not (200 <= resp.status_code < 300):
                raise ZohoAPIError(f"{resp.status_code} — {context}: {resp.text[:200]}")
            return resp.json()

        async def get_task(self, zoho_task_id: str) -> dict[str, Any]:
            """
            Fetch a single Zoho Tasks record by ID.
            Returns the full response dict: {"data": [{...record...}]}.
            Raises ZohoAuthError/ZohoNotFoundError/ZohoRateLimitError/ZohoAPIError.
            """
            async with httpx.AsyncClient() as client:
                resp = await client.get(
                    f"{self.base_url}/Tasks/{zoho_task_id}",
                    headers=self._headers(),
                )
            return self._handle(resp, f"GET /Tasks/{zoho_task_id}")

        async def get_fields_metadata(self, module: str = "Tasks") -> dict:
            """
            Fetch field metadata for a Zoho module and resolve:
              - todoist_task_id_api_name: the api_name of the custom field whose field_label contains "Todoist"
                (or None if not found — caller should log WARN and continue)
              - status_picklist_values: the list of actual_value strings from the Status picklist
                (or [] if Status is not a picklist field)
            Required OAuth scope: ZohoCRM.settings.fields.ALL
            """
            async with httpx.AsyncClient() as client:
                resp = await client.get(
                    f"{self.base_url}/settings/fields",
                    params={"module": module},
                    headers=self._headers(),
                )
            body = self._handle(resp, f"GET /settings/fields?module={module}")
            fields = body.get("fields", [])

            todoist_field_api_name: str | None = None
            status_values: list[str] = []

            for field in fields:

                if field.get("custom_field") and "Todoist" in (field.get("field_label") or ""):

                    status_values = [

            )

        async def fetch_tasks_modified_since(
            self,
            since: datetime,
            owner_id: str,
        ) -> list[dict[str, Any]]:
            """
            Search Zoho Tasks where Modified_Time >= since AND Owner == owner_id.
            Returns a flat list of raw record dicts, concatenated across all pages.
            - Timestamp is always formatted as ISO8601 with explicit +00:00 UTC offset.
            - Criteria ALWAYS includes both Modified_Time and Owner — never a full scan.
            - HTTP 204 is treated as valid empty result (returns []).
            - Pagination terminates when info.more_records is False.
            """
            since_str = since.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S+00:00")
            criteria = (
                f"((Modified_Time:greater_equal:{since_str})"
                f"and(Owner:equals:{owner_id}))"
            )
            results: list[dict[str, Any]] = []
            page = 1
            while True:
                async with httpx.AsyncClient() as client:
                    resp = await client.get(
                        f"{self.base_url}/Tasks/search",
                        params={"criteria": criteria, "page": page, "per_page": 200},
                        headers=self._headers(),
                    )
                if resp.status_code == 204:
                    # Valid empty result — DO NOT call _handle.
                    break
                body = self._handle(resp, f"GET /Tasks/search page={page}")
                results.extend(body.get("data", []))
                info = body.get("info") or {}
                if not info.get("more_records"):
                    break
                page += 1
            return results
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker process → Zoho CRM v8 EU API | Access token (bearer credential) crosses out; JSON record data crosses in and is later parsed |
| Zoho API response → application memory | Response JSON is untrusted input; missing keys or unexpected shapes must be handled defensively |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `ZohoClient.access_token` | mitigate | Access token is a dataclass attribute; never passed to `log.info`/`log.error`. Only `Authorization` header string is sent over TLS to `zohoapis.eu`. No token value appears in any log event added in this plan. |
| T-02-02 | Information Disclosure | `log.error` on API failures | mitigate | `_handle` error messages include only status code and at most 200 chars of response body (`resp.text[:200]`) — never the `Authorization` header or access token. |
| T-02-03 | Tampering | Zoho API response parsing | mitigate | Defensive `.get("fields", [])`, `.get("data", [])`, `.get("info") or {}` — missing keys produce empty list / None, not KeyError. `field_label` and `api_name` accessed via `.get()`. |
| T-02-04 | Denial of Service | Retry storm on 401 | mitigate | 401 raises `ZohoAuthError` which is NOT caught inside the client; caller (Plan 02 refresh loop / future Plan 05 sync_task) must stop and alert per INFRA-6. |
| T-02-05 | Denial of Service | Unbounded pagination loop | mitigate | Loop terminates on `info.more_records == False` OR HTTP 204. Zoho's per_page cap (200) bounds per-page size; per-page fetch is authenticated and rate-limited by Zoho. No manual page cap needed for v1. |
| T-02-06 | Spoofing | TLS to zohoapis.eu | mitigate | httpx verifies TLS certificates by default; `zohoapis.eu` uses HTTPS. No `verify=False` anywhere. |
| T-02-07 | Repudiation | Unclear error source | mitigate | Every typed exception includes a `context` string (`"GET /Tasks/{id}"`, `"GET /settings/fields?module=Tasks"`, `"GET /Tasks/search page={page}"`) so downstream logs identify the failing call. |
