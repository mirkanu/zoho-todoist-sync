<objective>
Implement the reconcile_sweep cron function (SEED-5) — the primary catch-all for missed webhooks and dropped jobs. The sweep fetches Zoho tasks modified in the last 20 minutes, fetches the Todoist incremental delta via sync_token, computes canonical hashes, and enqueues sync_task jobs for any task with a hash mismatch. Persists the Todoist sync_token (SEED-7) and the last_run timestamp after each sweep.

Purpose: Make the system self-healing — even if every webhook fails, edits are picked up within 20 minutes via this sweep alone (success criterion SC-2 of Phase 7).

Output: `app/worker/reconciler.py` (new module containing reconcile_sweep) plus `tests/unit/test_reconciler.py` (new test file). The orphan_sweep function and WorkerSettings.cron_jobs registration are deferred to Plan 02.
</objective>
