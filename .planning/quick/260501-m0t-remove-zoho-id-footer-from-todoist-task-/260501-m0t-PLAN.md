# Quick Task 260501-m0t: Remove [zoho:ID] footer from Todoist task descriptions

## Rationale

The `sync_state` table already provides the bidirectional `zoho_task_id ↔ todoist_task_id` mapping via an indexed lookup. The `[zoho:ZOHO_TASK_ID]` footer written into Todoist task descriptions is therefore redundant.

The only remaining use was in the `item:added` webhook handler — to distinguish sync-managed tasks (footer present) from native tasks (no footer). However, `item:added` with a footer is just an echo of the worker's own Zoho→Todoist write, which gets suppressed by hash-match echo suppression anyway. So all `item:added` events can safely be discarded without checking the footer.
