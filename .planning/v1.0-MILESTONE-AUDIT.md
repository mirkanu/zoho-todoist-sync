## Post-v1 Architecture Change (quick-260501-m0t)

Quick task 260501-m0t (commit 383f270, 2026-05-01) made a significant architecture change **after** Phase 8 completion:

| Before | After |
|--------|-------|
| Todoist task description includes `[zoho:ID]` footer | No footer; sync_state DB column provides ID linkage |
| item:added handler checks footer → enqueues if found | item:added always discarded unconditionally |
| Reconciler uses footer parsing for Todoist delta | Reconciler uses sync_state DB lookup |
| EDGE-8: re-attaches missing footer | EDGE-8: no longer needed, removed |
| migrate.py stamps footer on existing pairs (SEED-3) | migrate.py does not stamp footers |

**Verdict:** This simplifies the system and removes a fragility (user edits breaking footer). The requirements SYNC-5, LOOP-5, EDGE-8, SEED-3 as written describe the old design. The current implementation is architecturally cleaner. These should be noted as superseded in REQUIREMENTS.md.
